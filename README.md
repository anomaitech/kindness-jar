# Kindness Jar

A small app for encouraging kids' good behavior. Log good deeds for points, track "oops" strikes (3 strikes takes points away, and "Made it right" clears one), and trade points for rewards you choose.

Everything is saved in the browser on each device. Use **Setup → Backup** to move a jar to another phone.

## Deploy on GitHub Pages
1. Push these files to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
5. On your phone, open that link and choose **Add to Home Screen**.
